# The case (use verbatim spirit, may rephrase lightly)
Uber Eats has strong overall growth, but weekday lunchtime orders from 11:30am to 1:30pm are 30% lower than dinner orders. That observation is ALL you have. No backlog, no personas, no research, no strategy doc exists at the start. Everything gets built through the guide, in sequence, from discovery through go to market. Shorthand name: "the lunch gap".

# The sequence (artifact chain; each guide consumes earlier outputs by name)
Phase 1 Discover: research-hypothesis -> customer-interviews -> jtbd-framing -> personas-archetypes -> continuous-discovery -> journey-mapping
Phase 2 Shape the value: value-proposition (VPC + value statements) -> pmf-canvas (Olsen) -> business-canvases (Lean Canvas) -> four-risks
Phase 3 Decide and scope: kano-model -> prioritization (RICE + MoSCoW + cost of delay) -> innovation-games (20/20 Vision, Buy a Feature, Prune the Product Tree, Speed Boat) -> scoping-mvp -> story-mapping
Phase 4 Specify: strategy-kernel -> metrics-trees (KPIs) -> okrs -> prd -> story-writing -> states-and-edges
Phase 5 Validate: experiment-design -> usability-testing -> heuristic-eval
Phase 6 Go to market: positioning -> pricing -> gtm-launch -> roadmapping -> go-roadmap
Reference (not in the arc): everything else (moats, premortem, working-backwards, briefs-and-cases, remaining design skills, core skills).

# Exercise model (STRICT, replaces the old one)
Rows in every step are exactly: Search / Get / Build / Capture.
- Search: the prompt typed into Claude. Unchanged style.
- Get: what to come away with.
- Build: DO the work on the lunch gap. May only use (a) the case observation and (b) artifacts produced by EARLIER guides in the sequence, named explicitly ("the two personas you built in Personas and Archetypes"). Never "take your backlog", never "hand out", never assume pre-existing material. If real user access would be needed, have Claude simulate it and say so ("ask Claude to play a desk-bound office worker; interview it with your script").
- Capture: plain instruction to write their rule or artifact into their doc, one or two sentences, own words. NO <span class="fill"> blanks anywhere. Give a starting stem as quoted guidance if helpful, e.g. Write one sentence that starts "A persona earns its place when ...".
Each guide's final "Make it a skill" block stays, and its test line uses the lunch gap.
